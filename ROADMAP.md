# Roadmap

## 0.1

- Local daemon, CLI, Python SDK, TypeScript SDK, React console, SQLite store, and optional MCP bridge.

## 0.2

- Expanded gRPC client stubs, richer console graph rendering, adapter hardening, and benchmark reporting.

## 0.3

- Experimental single-primary local cluster mode with worker forwarding and stronger operational diagnostics.

## Later

- Hosted dashboard, team workspaces, cloud sync, long-term retention, RBAC, SSO/SAML, audit exports, production alerting, incident replay, enterprise support, and private deployment.
