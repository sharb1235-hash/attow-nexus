Use Common Room to understand public GitHub community signals after launch. This is a manual founder setup task. Do not commit Common Room tokens or OAuth credentials.

## Manual Setup

- Create a Common Room account manually.
- Prefer "Sign up with Google" if available.
- Use `sharb1235@gmail.com`.
- Connect GitHub repository `sharb1235-hash/attow-nexus`.
- Grant only required GitHub scopes.
- Confirm ingestion of:
  - stars
  - forks
  - issues
  - pull requests
  - discussions if enabled
  - comments
