# Company Launch Checklist

This is an operational checklist, not legal advice.

- [ ] Certificate of formation issued.
- [ ] Complete post-incorporation setup.
- [ ] Issue founder stock.
- [ ] File 83(b) election if applicable and within the deadline.
- [ ] Sign IP assignment to Attow, Inc.
- [ ] Assign provisional patent application to Attow, Inc. after the appropriate assignment document is signed.
- [ ] Update GitHub repo ownership later if desired.
- [ ] Open company bank account after EIN.
- [ ] Keep copies of all documents.

Do not commit confidential IDs, certificate numbers, addresses, founder stock details, private legal documents, or unsigned assignment claims to this repository.
