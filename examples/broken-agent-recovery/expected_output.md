# Expected Output

The demo prints commit IDs generated by the local daemon, so exact values change on every run.

Expected shape:

```text
# Attow Nexus Broken Agent Recovery Demo

1. Planner created plan
   commit: c_...

2. Coder produced invalid state
   commit: c_...

3. Reviewer detected failure
   commit: c_...
   error: retry_limit must be an integer

Bad transition detected:
LAST GOOD COMMIT: c_...
BAD COMMIT: c_...

Try:
cargo run -p nexus -- diff c_last_good c_bad
cargo run -p nexus -- replay c_last_good

4. Replayed last good state and applied fix
   RECOVERY COMMIT: c_...

5. Reviewer passed
   FINAL PASS COMMIT: c_...

Inspect:
cargo run -p nexus -- log --run broken-agent-demo
cargo run -p nexus -- diff c_last_good c_bad
cargo run -p nexus -- diff c_last_good c_recovery
cargo run -p nexus -- replay c_final
```

The bad transition is the coder commit that changes `retry_limit` from planned integer state to the invalid string `"five"`. Replay is limited to captured logical agent state and does not undo external side effects.
